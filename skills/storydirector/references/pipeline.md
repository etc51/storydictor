# Запуск конвейера внутри Codex

Исполняемый вход: `scripts/pipeline.py`. Python — путь установленного runtime. Перед началом проверь профиль и создай отдельный проект командой `init --project <folder> --topic <topic>`.

Codex самостоятельно пишет story.json и visual_bible.json, затем запускает `run --project <folder>`. Ответ needs_agent является внутренней задачей Codex, не вопросом пользователю: прочитай agent_tasks.json, выполни задания и продолжи run. При final_review проверь материалы, запиши creative_qa.json с passed, reviewed_story_hash и reviewed_film_hash (SHA256 текущих файлов) и заверши командой finish. При дефекте исправь его и повтори затронутые этапы. Сценарий и изображения создаются инструментами агента, CLI не генерирует их самостоятельно.

До новых озвучки/изображений и сборки действует [редакторский допуск](story-editorial.md). `editorial_qa.json` связывает точный narration snapshot с двумя независимыми полными отчётами и их SHA256. `scripts/editorial_guard.py --project <folder> --story <folder>/story.json` проверяет свидетельства и совпадение озвучиваемого текста; guard не оценивает литературный вкус. Отсутствие проверки, stale hash, self-review, незакрытый blocker или limited_review дают внутреннее `needs_agent/story_editorial`, не запрос разрешения пользователя. Новый платный API вызов проверяет допуск до отправки; существующий completed cache доступен без повторной оплаты, running/uncertain требует восстановления и не повторяется. Правки текста требуют нового допуска и адресной проверки зависимостей. Прямые image_gen вызовы агента также обязаны предварительно пройти guard: CLI не перехватывает инструменты вне Python.

Минимальный story.json:

```json
{
  "title": "Название",
  "chunks": [{"id": "C001", "text": "[serious] Точный текст диктора."}],
  "shots": [{"id": "K001", "chunk_id": "C001", "start_word": 0, "prompt": "Описание кадра", "light_pulse": false}],
  "soundtrack": []
}
```

Короткие chunks до 4500 символов завершаются смысловой паузой. Не придумывай метки слов: start_word задаёт индекс распознанного слова внутри chunk (начиная с нуля), не символа и не секунды. После первого STT прочитай audio/words.json и скорректируй смысловые границы планов, прежде чем генерировать картинки. У каждого chunk минимум один план; его планы упорядочены, первый start_word=0, остальные уникальны и возрастают. Проверка распознавания может требовать нормализации чисел и имён; вручную исправляй точные различия только после проверки звука, не понижай порог ради прохождения.

Картинки: Готовые_изображения/K001.png. humorous_object_text содержит точную смешную надпись либо отсутствует; visual_gag содержит описание визуального гэга либо отсутствует. В 50% уникальных сюжетных кадров должен быть хотя бы один из этих признаков (округление вниз); оба признака в одном кадре считаются один раз. Библия героев и референсы принадлежат текущему проекту. Для массовой генерации обязательно примени [«сторикартинки»](../../story-images/SKILL.md), который использует встроенный image_gen через исполнителей и очередь scripts/image_queue.py. Скрипт очереди не генерирует картинки: этим занимаются агенты. Координатор переносит только approved версии в Готовые_изображения с проверкой SHA256 и соответствия image_id/версии библии, сохраняет visual_lore_qa.json и обновляет необходимые для текущего pipeline image_qa/manifest записи. Формат принятого кадра остаётся совместимым с K001.png; база image_jobs/queue.sqlite3 не заменяет manifest конвейера. Уже существующие файлы сначала проверь и импортируй как результаты с фактическим QA, не перегенерируй автоматически. Для выдачи Codex создаёт отдельную обложку, с собственной визуальной проверкой.

Звуковое событие: `{"file":"assets/theme.mp3","kind":"music","start_s":0,"duration_s":30,"gain_db":-20,"loop":true,"provenance":"ElevenLabs; created during paid subscription; source ID ..."}`. Музыка размещается только где нужна, темы используются повторно; voice sidechain снижает фон во время речи. Для автоматической генерации вместо file укажи prompt и source_duration_s: конвейер вызывает Music/SFX API с кешированием и записывает soundtrack_manifest.json. Music source 3–300 секунд, SFX source 0.5–30 секунд. Проверь условия использования выбранной музыки для конкретного выпуска.

Для повторного использования аудио chunk может содержать audio_file и transcript_file. Это реальные файлы, не simulated. API-запросы кешируются по входам; неизвестный исход платного вызова блокируется от повтора. При штатном возобновлении готовый голос/STT не оплачиваются повторно. Операции локального микширования пока пересчитываются.

account-check читает свежую подписку через user_read; при отсутствии права сообщи конкретный технический блокер. Не расширяй права без требуемого средой подтверждения. Доплаты не включать. Перед каждым новым платным вызовом проверяется свежий остаток с консервативной оценкой кредита и запасом 25%; ставки модели могут меняться, поэтому агент проверяет их перед большим запуском. Отдельно проверь доплаты/PAYG в аккаунте: проверка legacy extension не подтверждает отсутствие предоплаченного PAYG.

foreground_file в плане — путь к отдельному прозрачному PNG переднего плана, background — обычный K001.png без этого объекта. Рендер двигает слои с различной скоростью. Не вырезай объект без восстановления фона: это создаёт дубликат. Подготовку слоёв выполняй по правилам imagegen. Изменение слоя инвалидирует кеш клипа.

Если speech_qa выявляет различие, агент проверяет звук и исправляет текст/озвучку либо записывает в speech_qa_approval.json соответствие chunk ID → comparison_hash из отчёта. Разрешение действует только для конкретных текущих текста, распознавания и аудиофайла. Нельзя утверждать ошибки произношения ради прохождения проверки.

Выход: render/film.mp4, audio/mix.wav, subtitles.srt, cover.png, manifest.json, render/qa.json и creative_qa.json. Техническая сборка ещё не художественное утверждение. Конвейер работает в активном Codex; отдельного фонового сервиса и автопубликации нет.
