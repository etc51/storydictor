# StoryDictor

**От темы до оригинальной видеоистории: сценарий, независимая редактура, эмоциональная речь, проверенные кадры и MP4.**

[English](README.md) · [Описание для каталога](docs/catalog-description.ru.md) · [Лицензии](THIRD_PARTY_NOTICES.md)

StoryDictor — плагин с навыками для локальной работы ChatGPT/Codex. Основной навык называется `storydirector`; «сторикартинки» — `story-images`. В пакете находятся инструкции, локальные производственные инструменты и выбранные редакторские методики. Активный агент выполняет творческую работу и проверки; Python помогает с очередью, озвучкой, таймкодами, звуком и монтажом.

Это не отдельный сервер и не фоновый генератор фильмов. Полное производство требует доступных инструментов агента и настроенного компьютера. Подписка, API-ключи и готовые фильмы в пакет не входят.

## Что умеет

- Исследовать тему, мир, эпоху и ограничения по источникам до сценария.
- Создавать оригинальную личную судьбу, характеры, отношения, причинные переходы и заслуженный финал.
- Работать в формате «история лестница»: одна непрерывная жизнь, рост возможностей, влияния и ответственности через решения и их последствия.
- Проверять полный сценарий отдельным критиком и свежим читателем; исправлять проблемы до дорогих зависимых этапов.
- Создавать индивидуальную библию персонажей, возрастные версии, одежду, окружение и референсы.
- Направлять эмоциональную подачу рассказчика: намерение, темп, акценты, паузы и переходы по смыслу сцены.
- Получать реальные метки речи и SRT; сравнивать распознанный текст с исходником.
- Координировать массовую генерацию отдельных изображений через очередь, независимых исполнителей и визуальную проверку.
- Проверять визуальный лор: пейзажи, архитектуру, интерьеры, одежду, броню, оружие, транспорт, технику, символику и реквизит.
- Делать локальное движение камеры и света, а при подготовленных слоях — параллакс. Анимация персонажей и внешний video API не подключаются автоматически.
- Подбирать музыку и эффекты, сохранять происхождение материалов, собирать и проверять H.264/AAC MP4, обложку и пакет описания.

## Стандарт выпуска

| Параметр | Значение по умолчанию |
|---|---|
| Длительность | 25–35 минут |
| Изображения | 150–200 уникальных сюжетных кадров |
| Напряжённые сцены | Смена каждые 4–8 секунд |
| Обычное повествование | 10–15 секунд |
| Отдельные эмоциональные паузы | 20–25 секунд |
| Видео | 16:9, 1920×1080, 24 fps |
| Подача | Один выразительный рассказчик |
| Движение | Камера, свет, переходы; параллакс при реальных отдельных слоях |

Референсы, обложки, неудачные варианты, исправления и кропы не увеличивают число уникальных сюжетных кадров. План строится по событиям и реальной речи, а не равномерным делением хронометража. По умолчанию половина кадров содержит уместный визуальный гэг или надпись на предмете; тяжёлые драматические сцены не должны разрушаться шутками. Прямые требования пользователя имеют приоритет.

## Независимая редактура

`сценарист → критик → свежий читатель → исправления → проверка новой версии`

Критик получает неизменяемый полный текст, требования и источники. Другой свежий агент читает тот же текст, получив только описание аудитории. Он не видит библию, объяснения автора или критику. Оба связывают наблюдения с конкретными цитатами и SHA256 текста.

Координатор исправляет мотивацию, причинность, повторения, провалы напряжения и неподготовленные развязки, сохраняя сильные сцены. Два обычных цикла исправления ограничивают бессмысленную полировку; при сохранении существенной проблемы перерабатывается план или честно сохраняется `needs_revision`.

`editorial_guard.py` проверяет наличие и происхождение отчётов, хеши, полноту, цитаты и судьбу замечаний. Он не оценивает художественный вкус. Автор не может снять блокер собственной пометкой `resolved`. Новый текст требует новой полной проверки. Симуляция читателя — субъективный сигнал, а не опрос аудитории или прогноз удержания.

## Эмоции и качество речи

Режиссёрские заметки хранятся отдельно от читаемого текста. Выбирайте реально доступный голос и модель, применяйте только поддерживаемые ими средства управления. Сцены страха, усталости, гордости и облегчения не должны звучать одинаково.

Нужно проверять пропуски, повторы, произношение, случайное чтение тегов, шумы, клиппинг и важные эмоциональные переходы. STT и декодирование проверяют содержание и техническую исправность; они не подтверждают актёрскую выразительность. Если доступного прослушивания нет, это ограничение записывается в QA.

## Установка

После публикации и одобрения в общем каталоге установите StoryDictor в ChatGPT/Codex. GitHub-публикация сама по себе не означает одобрение каталога.

Для установки из репозитория в поддерживаемом локальном клиенте:

```bash
codex plugin marketplace add etc51/storydictor --ref main
```

Откройте каталог плагинов настольного приложения, выберите источник StoryDictor и установите плагин. При необходимости обновите или перезапустите приложение после завершения текущих задач. Репозиторий содержит `.agents/plugins/marketplace.json`, переносимый `plugin.json` и совместимый `.codex-plugin/plugin.json`.

Можно также скопировать все каталоги из `skills/` в каталог навыков вашего клиента. Для основного конвейера нужны включённые зависимые навыки; копирование одного `storydirector` не заменяет весь пакет.

## Настройка компьютера

1. Нужны инструменты исследования, генерации и просмотра изображений, файловый доступ и независимые агенты. Навык не создаёт отсутствующие инструменты.
2. Установите Python 3.10+, FFmpeg, ffprobe и curl. Для заголовков нужен Pillow и TrueType-шрифт, поддерживающий язык истории. Для нестандартного пути curl задайте `tools.curl`.
3. Запустите `storydictor-setup`. Шаблон профиля: `skills/storydirector/references/local-profile.json`.
4. Для ElevenLabs настройте `ELEVENLABS_API_KEY` через переменную среды/менеджер секретов. Не отправляйте ключ в чат и не сохраняйте его в Git.
5. Выберите голос и модель по актуальному доступу аккаунта. Идентификаторы в шаблоне намеренно пустые; чужие квоты и права не наследуются.
6. В каждом выпуске храните собственный `production_profile.json`: язык, пути программ/шрифта, аудиопровайдер, разрешённые материалы и настройки.

```bash
python -m pip install -r requirements.txt
python skills/storydirector/scripts/pipeline.py init --project output/my-story --topic "Одна жизнь на опасной дороге"
```

Агент готовит `story.json`, библию, редакторские отчёты и согласованные материалы. Далее:

```bash
python skills/storydirector/scripts/editorial_guard.py --project output/my-story --story output/my-story/story.json
python skills/storydirector/scripts/pipeline.py run --project output/my-story
python skills/storydirector/scripts/pipeline.py status --project output/my-story
```

`needs_agent` — задание активному агенту, а не автоматическое требование утверждения пользователем. CLI сам не пишет сценарии и не вызывает встроенную генерацию картинок.

## Очередь изображений и возобновление

«Сторикартинки» использует транзакционную SQLite-очередь с постоянными ID, версиями, зависимостями, хешами, lease, журналом и ограниченными исправлениями. Реальная параллельность зависит от слотов и доступа инструмента; 150 кадров не означает 150 одновременных вызовов.

Неизвестный исход запроса расследуется до повтора. Изменение библии создаёт новые версии пакетов и переоценку зависимых кадров. Только координатор обновляет общие manifest и QA. Старые используемые материалы сохраняются; удаление заменённых файлов требует явного разрешения и безопасной проверки зависимостей.

После редакторской правки заменяются затронутые речь, метки, планы, изображения и монтаж. Хорошие независимые результаты не генерируются заново без причины. Подробности — в `skills/story-images/references/parallel-production.md`.

## Затраты, права и выдача

Полное производство может расходовать включённую квоту вашего ElevenLabs. Проверяйте её перед новыми платными операциями и учитывайте параллельные выпуски. Пакет не подключает доплаты, PAYG, новые подписки или внешний генератор ради скорости. Проверяйте условия использования музыки, голосов, источников мира и материалов для конкретной публикации.

Итоговый комплект: проверенный MP4, отдельная обложка, SRT, название, описание и проект. Адрес сообщества и площадки задаются пользователем. Публикация на YouTube, Rutube, VK Видео или другой площадке — отдельное поручение.

## Проверки разработки

```bash
python -m unittest discover -s skills/storydirector/scripts -p "test_*.py" -v
python skills/story-images/scripts/test_image_queue.py
```

Тесты используют временные и синтетические материалы, без платной генерации. Они проверяют сохранность, хеши, очереди и запреты, а не популярность историй или качество актёрской подачи. См. `docs/REVIEW_GUIDE.md` для сценариев проверки пакета.
